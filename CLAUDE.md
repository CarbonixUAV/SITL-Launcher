# SITL Launcher V2

## Overview

Avalonia-based launcher for ArduPilot SITL (CxPilot), used internally at Carbonix for pilot training. Replaces the previous tkinter GUI (V1) and batch file approach (V0).

## Key Decisions

- **Avalonia over Electron/Tauri/WinForms** - Learning investment for future projects; modern XAML/MVVM patterns
- **Windows-only target** - GCS and RealFlight are Windows-based, no need for cross-platform
- **Parse launch.bat for frame/model** - Keeps V0 configs as source of truth, no migration needed, existing setups work on day one
- **Runtime folder separate from Versions** - eeprom.bin, logs, and terrain cache persist across version switches
- **Sync config files on version change only** - When switching versions, clobber scripts/defaults/jsons and delete stale files, but don't touch if staying on same version (preserves user additions)
- **Last-used airport tracked per aircraft** - Keeps headless and RealFlight defaults separate naturally

## Launch Flow

1. User selects Version (e.g., `CxPilot-8.0.0-dev-b525b03b`)
2. Aircraft dropdown populates from subfolders of that version
3. User selects Aircraft (e.g., `ottano-realflight`) - airport defaults to last-used for this aircraft
4. User selects Airport from configured list
5. On Launch:
   - If version changed since last launch for this aircraft, sync config files to Runtime (clobber + delete stale)
   - CWD = `Runtime/{aircraft}/`
   - Binary = `Versions/{version}/CxPilot.exe`
   - Args include: location coords, serial ports, frame/model (parsed from launch.bat), defaults path

## Frame Types

- `quadplane` - Used for `-headless` configs, includes a model JSON file (e.g., `-M quadplane:ottano-headless.json`)
- `flightaxis` - Used for `-realflight` configs, connects to RealFlight sim (e.g., `-M flightaxis`)

## Config File (config.json)

Stores:

- Airports: list of {name, lat, lon, alt, heading}
- Serial ports: global list (e.g., `tcp:0`, `udp:14550`), can add arbitrary number
- Per-aircraft last-used airport
- Per-aircraft last-used version (for detecting version changes)
